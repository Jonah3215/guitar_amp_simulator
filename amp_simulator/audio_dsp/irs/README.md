# Cabinet Impulse Responses

The impulse responses in this directory are third-party cabinet impulse responses from Jester Dyne Productions.

## Jester's Brutal Pack

Jester's Brutal Pack is distributed as CC0 / public domain and is free for commercial and non-commercial use. No attribution is required.

The pack contains impulse responses captured from a modified 4×12 Behringer BG412S cabinet using various speakers and microphones.

These files are included in this repository as third-party assets and are not original works of the Guitar Amp Simulator project.

For more information about the original impulse response pack, visit Jester Dyne Productions.
